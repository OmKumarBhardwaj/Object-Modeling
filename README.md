# Object Modeling — Contest Engine (Geektrust Challenge)

A Codeforces-style programming-contest engine built in core Java, submitted to the Geektrust backend challenge — scored 89/100 with six badges (readability, maintainability, functional/OO modelling, tests, correctness, build).

## Features
- Contest and leaderboard orchestration with precise simulated results
- Clean architecture with interfaces and SOLID design
- Extensive JUnit + Mockito test coverage

## Tech stack
Core Java · Clean Architecture · JUnit · Mockito

## Context
Built as part of [Crio.Do](https://www.crio.do/)'s project-based curriculum (2022–23) — one of a series of backend projects; see the full portfolio at [github.com/OmKumarBhardwaj](https://github.com/OmKumarBhardwaj).
